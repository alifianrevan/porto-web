Tentang Diri & Latar Belakang Komputasi

Saya adalah mahasiswa tingkat akhir Teknik Informatika di Universitas Pancasila dengan rekam jejak dedikasi 1,5 tahun sebagai Asisten Laboratorium Praktikum, mendampingi dan mengarahkan mahasiswa dalam memahami logika komputasi mendalam serta standar rekayasa perangkat lunak modern.

Fokus keahlian saya berakar pada Software Engineering, Full-Stack Web Development, dan Sains Data, dengan keahlian teknis membangun aplikasi desktop modular menggunakan Java (JavaFX, OOP, Maven), antarmuka web responsif dengan HTML5/CSS3 dan JavaScript, serta skrip analitis berbasis Python.

Dalam ranah manajemen data, saya mahir dalam Normalisasi Basis Data Relasional hingga 3NF menggunakan SQL, konstruksi query bertingkat, serta optimasi indeks. Keahlian ini disempurnakan dengan eksplorasi multidisiplin pada rancang bangun Internet of Things (IoT) dan analisis spasial citra satelit melalui ArcGIS & QGIS.
